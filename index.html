Python Wheelhouse

共 4 个 wheel、4 个项目、 3.8 MB。

客户端安装

pip install --find-links https://xleeyumi.github.io/auto-wheels/wheels/ --prefer-binary -r requirements.txt

完全离线（不访问 PyPI）：

pip install --no-index --find-links https://xleeyumi.github.io/auto-wheels/wheels/ -r requirements.txt

长期生效可写入 ~/.pip/pip.conf（Windows：%APPDATA%\pip\pip.ini）：

[global]
find-links = https://xleeyumi.github.io/auto-wheels/wheels/
prefer-binary = true

也可以当作 PEP 503 索引使用：

pip install --index-url https://xleeyumi.github.io/auto-wheels/simple/ --trusted-host xleeyumi.github.io
